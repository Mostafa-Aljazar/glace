## الملاحظات بالتفصيل

### 1. `flavors[].available` بيتحذف لما تكون `false` 🔴

```json
{ "id": "mango", "nameAr": "مانجا", "family": "classic",
  "image": "https://cdn.example.com/flavors/mango.jpg" }
                                    ← available مش موجود
```

النكهتين الناقصين هما **بالظبط** `mango` و`flora` — يعني الاتنين اللي المفروض
`available: false`. الباك بيحذف الحقل بدل ما يبعت `false`.

**السبب المرجّح (Laravel):** `array_filter()` بيرمي القيم الـfalsy، أو
`->when($x->available, ...)`، أو `whereNotNull` على العلاقة.

**المطلوب:** ابعت `"available": false` صراحةً.

```php
// غلط — بيرمي false
return array_filter([...]);

// صح
'available' => (bool) $flavor->available,
```

> ⚠️ **مهم:** الفرونت بيرفض الرد كله بدل ما يفترض `true`. ده **مقصود** — لو
> افترضنا `true` كانت المانجا والفلورا (المش متوفرين) هيبانوا قابلين للطلب
> والزبون يطلب حاجة خلصت.

ولاحظ: `items[].available` **شغّال صح** — 7 عناصر موقوفة والحقل موجود فيهم.
فالباج في serializer النكهات بس.

### 2. `family` مالوش `flavors` خالص 🔴

`cup` و`brad-boza` عندهم 23 نكهة، `family` عنده **صفر** — والحقل مش موجود أصلاً.
غالباً صفوف الـpivot `product_flavor` ما اتعملهاش seed للعائلي.

### 3. الصور — نصّها اتصلح، ونصّها بشكل غلط 🔴

**(أ) 70 رابط لسه `cdn.example.com`** — المنيو والنكهات كلها على الدومين الميت.

**(ب) الصور المرفوعة فعلاً بترجع كمسار نسبي** — `/home` بقى فيه 3 صور حقيقية
مرفوعة (اتأكدنا: 405KB PNG)، بس الباك بيرجّعها كده:

```json
"manImg": "hero-slides/01KZRAB31FVVSVVAJNQD8YH3BY.png"
```

من غير `http://` ومن غير `/` في الأول. الصورة نفسها متاحة على
`{origin}/storage/hero-slides/...` ✓

> **ده كان بيكسر الصفحة الرئيسية بـ500.** `next/image` بيرفض أي `src` مش مطلق
> ومش مبدوء بـ`/`. **اتصلح في الفرونت** — `resolveMediaSrc` بقى يحلّ المسارات
> النسبية على `{apiOrigin}/storage/`، فالصفحة شغّالة والصور بتتحمّل دلوقتي.

**المطلوب من الباك برضو:** يرجّع URL كامل. العقد (`swagger.yaml` →
`IProductVariant.image`, `format: uri`) بيطلب رابط مطلق. في Laravel:

```php
// بيرجّع مسار نسبي — ده اللي بيحصل دلوقتي
'image' => $slide->image_path,

// الصح
'image' => $slide->image_path ? Storage::disk('public')->url($slide->image_path) : null,
// أو
'image' => $slide->image_path ? asset('storage/'.$slide->image_path) : null,
```

الفرونت هيفضل شغّال في الحالتين — بس الرابط الكامل أوضح ولو الصور اتنقلت لـCDN
تاني ما تحتاجش تعديل.

### 4. `about.paragraphs` بشكل غلط 🟠

```json
"paragraphs": [{ "text": "..." }]   ← بيبعت كده
"paragraphs": ["...", "..."]        ← العقد
```

كان بيرمي `paragraph.slice is not a function` ويكسر قسم About بالكامل.
**اتصلح في الفرونت** بـshim بيفكّ الغلاف، بس المطلوب من الباك يبعت نصوص مباشرة.

> وده كشف إن الفاليديتر بتاع `/home` كان **سطحي** — بيتحقق من وجود `about` بس.
> اتعمّق فبقى يرفض أي شكل غلط عند الحدود بدل ما الكومبوننت يكسر.

### 5. صور أزرار «لماذا جلاسيه» — **مش من الباك** ⚪

الخلفيات الملوّنة تحت كل ميزة **زينة تصميم ثابتة في الفرونت** (أزرق/بني بالتناوب
حسب الموضع)، مش محتوى.

```json

```

`IHomeWhyFeature.image` **اتشال** من الـtypes والـswagger. لو الباك بعت `image`
هنا بيتجاهله الفرونت.

### 9. `events[].listImage` — ناقصة على 7 من 10 🟠

جدول الأدمن فيه حقل واحد بس: **«صورة البطاقة»** (300×400px). اترفع فعلاً لـ3
فعاليات (id 1، 2، 3)، والـ7 الباقيين (id 4-10) لسه من غيرها. مش باج — الأدمن
لسه ما رفعش. لو رفع الصور الناقصة، `listImage` تتصلح تلقائياً على كل الصفحات
(القائمة + الهوم + الفعاليات المرتبطة) لأنها بتشتق من نفس الحقل.

### 10. `events[].images[]` — **مفيش حقل رفع لها في الداشبورد خالص** 🔴

فحصنا شاشة تعديل الفعالية بالكامل — فيها «صورة البطاقة» بس. **مفيش حقل لمعرض
صور تفاصيل الفعالية (`images[]`)**. عشان كده كل الـ10 فعاليات (حتى اللي عندها
صورة بطاقة) بترجّع `"images": [null, null, null, null]`.

**قرار مؤقت اتخذ في الفرونت:** صفحة تفاصيل الفعالية بقت لو `images[]` فاضية
تعرض `listImage` بدالها (نفس الصورة، حقل تاني) بدل معرض فاضي بالكامل. وده حل
تجميلي بس — مش بديل عن معرض حقيقي.

**المطلوب:** جدول `images` منفصل (event_id, url, sort_order) + شاشة رفع متعددة
في تعديل الفعالية، زي ما موجود لصورة البطاقة بالظبط.

### 11. `home.events.items` — 3 بس، والمطلوب **10** 🟡

`/home` بيرجّع أحدث **3** فعاليات فقط (id 8، 9، 10 — دول بالظبط اللي مفيهمش
صورة بطاقة، عشان كده الهوم بيبان فاضي من الصور كمان). قسم «الفعاليات و
المناسبات» في الهوم عبارة عن **carousel (swiper)** بياخد أي عدد — مفيش أي حد
في الفرونت. غيّروا الـ`limit`/`take` في الكويري من 3 لـ**10**.
