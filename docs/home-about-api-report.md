# تقرير قسم About في الصفحة الرئيسية

**التاريخ:** 2026-08-06  
**الصفحة:** `http://localhost:3000` — قسم About  
**الـ API:** `GET https://glace-bzjj.onrender.com/api/home`  
**الحالة:** HTTP **200**

---

## الملخص

في قسم **«موهوبون في صناعة الآيسكريم !»** (الصورة المرفقة):

| العنصر | هل يرجع من الباك؟ | الملاحظة |
|---|---|---|
| العنوان | نعم | نفس نص الـ API |
| النص / الفقرات | نعم | نفس فقرات الـ API |
| صورة الشخصية | لا (فعلياً) | الباك يرسل رابط وهمي؛ الفرونت يعرض صورة محلية |
| زر «اعرف أكثر» | نعم | `ctaLabel` + `ctaHref` من الـ API |

---

## 1) الصورة — لا تظهر من الباك

### ما يظهر في الفرونت
صورة محلية (بنت مع آيس كريم وقبعة) من أصول المشروع (`ppp` / fake assets).

### ما يرجع من الباك
```json
"image": "https://cdn.example.com/home/about/character.png"
```

### السبب
- الدومين `cdn.example.com` **غير موجود** (placeholder).
- الفرونت يستبدل روابط الـ placeholder بصور محلية حتى لا تنكسر الصفحة (`hydrateHomePageMedia`).

### المطلوب من الباك
إرسال رابط صورة حقيقي وقابل للوصول، مثلاً:
`https://<cdn-حقيقي>/home/about/character.png`

---

## 2) النص — يرجع من الباك

### بيانات الـ API (`about`)
```json
{
  "title": "موهوبون في صناعة الأيسكريم !",
  "paragraphs": [
    "تأسس جلاسيه الأمير عام 2015 كأحد أفرع شركة أسكمو الأمير للإنتاج الغذائي، وقد نشأ الفرع ليكون متخصصاً في إنتاج وبيع الآيس كريم.",
    "تعمل الشركة على تقديم أجود أنواع الآيس كريم والبراد والعصائر الطبيعية والحلويات بأعلى معايير الجودة والنظافة."
  ],
  "image": "https://cdn.example.com/home/about/character.png",
  "ctaLabel": "اعرف أكثر",
  "ctaHref": "/about"
}
```

### مقارنة سريعة مع الـ fake المحلي
| | API | Fake |
|---|---|---|
| يذكر «للإنتاج الغذائي» | نعم | لا |
| يذكر «عماد الوادية عام 2000» | لا | نعم |

النص الظاهر في الشاشة يطابق **الـ API** وليس الـ fake.

---

## 3) باقي أقسام الـ Home (مرجع)

| قسم | الحالة | ملاحظة صور |
|---|---|---|
| `hero` (2 سلايدات) | بيانات حقيقية | كل الصور placeholder |
| `about` | بيانات حقيقية | الصورة placeholder |
| `whyGlace` (3 مميزات + فيديو) | بيانات حقيقية | صور المميزات + الثمبنيل placeholder؛ الفيديو YouTube شغال |
| `branches` (2 فروع) | بيانات حقيقية | خرائط Google OK |
| `events` (3 عناصر) | بيانات حقيقية | صور القائمة placeholder |

---

## الخلاصة / Action items

1. **صورة About:** الباك لازم يبدّل `cdn.example.com` بـ CDN حقيقي — حالياً الصورة **لا ترجع بشكل صالح من الباك**.
2. **نص About:** راجع من الباك ويعرض في الفرونت بشكل صحيح.
3. نفس مشكلة الصور موجودة في hero / whyGlace / events على الـ home.
